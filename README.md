# Urban Resource Consumption Analysis & Prediction

## 📌 Overview

This project analyzes urban resource consumption in Mumbai, focusing on energy, water, and waste. It uses data analytics and machine learning to identify patterns and predict future demand.

---

## 🎯 Objectives

* Analyze historical resource consumption data
* Study relationship between population and resource usage
* Build predictive models using machine learning
* Forecast future demand

---

## 📊 Dataset

The project uses real-world datasets:

* Energy consumption data
* Population data
* Water consumption data
* Solid waste data

Sources include:

* data.gov.in
* CPCB
* CWC
* BMC

---

## ⚙️ Technologies Used

* Python
* Pandas, NumPy
* Matplotlib, Seaborn
* Scikit-learn

---

## 🔍 Methodology

1. Data cleaning and preprocessing
2. Exploratory Data Analysis (EDA)
3. Correlation analysis
4. Machine Learning models:

   * Linear Regression
   * Polynomial Regression
5. Multi-feature modeling (Year + Population)
6. Future prediction

---

## 🤖 Machine Learning Approach

* Initial model used only "year"
* Improved model uses:

  * Year
  * Population
* Future population is predicted first and then used for resource prediction

---

## 📈 Results

* Resource consumption increases over time
* Strong correlation with population growth
* Polynomial model performed better
* Model successfully predicts future trends
